Services & ports

Each service is a Docker container on 127.0.0.1:<port>, given its own tailnet name with tailscale serve.

Every address is https://<name>.tailaccc17.ts.net. Pick a free port for a new service from this table.

What is being served

tailscale serve status

Add a service

Define the service with port tcp:443 in the Tailscale admin console first, then:

sudo tailscale serve --service=svc:<name> --https=443 127.0.0.1:<port>

Then approve the host on the admin console's Services page. Leave Funnel off.

Deploy

My apps (code in a git repo in the home folder)

cd ~/<repo>
git pull
docker compose up -d --build

The JoanPi homepage only needs git pull: its files are mounted into the container, so nothing has to be rebuilt.

Third-party images (AdGuard, Baby Buddy…)

cd ~/docker/<service>
docker compose pull
docker compose up -d

The container restarts on the new image; config and data in mounted volumes are untouched. Check with docker ps afterwards.

Docker

Running containers / all containers

docker ps
docker ps -a

Logs

docker logs <container> --tail 50
docker logs -f <container>
docker logs <container> --since 1h

Restart a container

docker restart <container>

Stop and start via compose

docker compose down
docker compose up -d

CPU and RAM per container, right now

docker stats --no-stream

Disk used by images, containers and volumes

docker system df

Remove dangling images left by rebuilds

docker image prune

Without -a this only removes untagged leftovers. With -a it also removes images no container uses, which then need pulling again.

Health

Temperature

vcgencmd measure_temp

Undervoltage and throttling

vcgencmd get_throttled

throttled=0x0 means all clear. Anything else means undervoltage or throttling happened since boot: check the power supply first, as a weak one is a common cause of SD card corruption.

Memory, disk and uptime

free -h
df -h
uptime

Size of each container's log file

sudo du -h /var/lib/docker/containers/*/*-json.log | sort -h | tail

System logs

sudo journalctl -xe
sudo journalctl -p err -b

The second shows only errors since the last boot.

Network

Current IP address

hostname -I

Detailed network info

ip a

Verify the static IP config (NetworkManager)

nmcli connection show
nmcli con show "YOUR_CONNECTION_NAME"

Is the static IP active?

ip a | grep wlan0 -A 3

Look for noprefixroute, not dynamic.

Maintenance

Update system packages (monthly)

sudo apt update && sudo apt upgrade -y
sudo reboot

Shut down / reboot

sudo poweroff
sudo reboot

AdGuard

Web interface: adguard.tailaccc17.ts.net on the tailnet, or http://192.168.0.21 at home.

Is it running?

docker ps | grep adguard

Recent logs

docker logs adguard --tail 50

Troubleshooting

DNS not working?

docker ps
docker logs adguard

A tailnet address doesn't load?

tailscale serve status
docker ps

If the container is up and the service is listed, check the Tailscale admin console to see that joan-pi is connected.

Pi not responding?

  • Router admin page → DHCP clients
  • Look for joan-pi or 192.168.0.21

Lost SSH access? With a monitor and keyboard:

ip a
systemctl status ssh

The first checks whether the IP changed; the second whether SSH is running.
